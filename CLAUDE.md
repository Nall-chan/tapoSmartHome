# Diese Library: tapo SmartHome  

- Diese Library dient zur Anbindung von tapo-Geräten, an die Software IP-Symcon. Sie stellt die notwendigen Module und Funktionen bereit, um tapo-Geräte in IP-Symcon zu integrieren und zu steuern.
- Die Library ist so konzipiert, dass sie leicht erweiterbar ist, um fehlende Abschnitte zu ergänzen.
